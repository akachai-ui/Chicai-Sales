# Chicai-Sales (ระบบบริหารงานขาย & CRM) 🚀

ระบบเว็บแอปพลิเคชันสำหรับบริหารจัดการงานขาย ลูกค้าสัมพันธ์ ออกใบเสนอราคา และติดตามสถานะงานแบบครบวงจร ออกแบบมาเพื่อทีมขายและฟรีแลนซ์ยุคใหม่

---

## ✨ ฟีเจอร์หลักของระบบ (Core Features)

1. **📊 ภาพรวมงานขาย (Dashboard & Analytics)**
   - สรุปตัวเลขยอดขายปิดสำเร็จ (Total Revenue)
   - มูลค่าในกระบวนการขาย (Pipeline Value)
   - อัตราการปิดการขาย (Win Rate %)
   - Sales Funnel แสดงสถิติและมูลค่าในแต่ละขั้นตอน
   - รายการดีลล่าสุดและงานด่วนที่ต้องติดตาม

2. **🔄 กระดานติดตามงานขาย (Sales Pipeline & Kanban)**
   - มุมมอง Kanban Board แบ่งตาม 6 ขั้นตอนการขาย:
     1. Lead เข้าใหม่ (Lead In)
     2. ติดต่อแล้ว (Contacted)
     3. เสนอราคา (Proposal Sent)
     4. เจรจาต่อรอง (Negotiation)
     5. ปิดการขายสำเร็จ (Closed Won 🎉)
     6. ปิดการขายไม่สำเร็จ (Closed Lost)
   - สลับสถานะได้ทันที พร้อมคำนวณโอกาสปิดการขาย (%)
   - ระบบค้นหาและกรองดีลตามสถานะ

3. **👥 ลูกค้าและผู้ติดต่อ (Customer CRM)**
   - จัดการฐานข้อมูลลูกค้าบุคคล และนิติบุคคล/บริษัท
   - ข้อมูลติดต่อ เบอร์โทรศัพท์ อีเมล ที่อยู่ออกใบกำกับภาษี เลขผู้เสียภาษี
   - ระบบแท็ก (#VIP, #Enterprise, #SME ฯลฯ)
   - ดูประวัติดีลและใบเสนอราคาย้อนหลังของลูกค้ารายนั้นๆ ได้ทันที

4. **📄 จัดการใบเสนอราคา (Quotation Generator & Print)**
   - สร้างใบเสนอราคา เลือกลูกค้าและสินค้าจากแคตตาล็อก
   - คำนวณส่วนลด, ภาษีมูลค่าเพิ่ม (VAT 7%) และยอดรวมสุทธิอัตโนมัติ
   - หน้าแสดงใบเสนอราคาทางการ พร้อมสั่งพิมพ์หรือบันทึกเป็น PDF (Print-ready)
   - สลับสถานะเอกสาร: ร่าง (Draft), ส่งแล้ว (Sent), อนุมัติ (Approved), ไม่อนุมัติ (Rejected)

5. **📦 สินค้าและบริการ (Products & Pricing Catalog)**
   - แคตตาล็อกสินค้า รหัสสินค้า หมวดหมู่ และหน่วยนับ
   - กำหนดราคาขายและต้นทุน
   - ติดตามจำนวนสต็อกคงเหลือ

6. **📅 กิจกรรมและการติดตามผล (Activities & Follow-ups)**
   - บันทึกการโทร (Call), การประชุม (Meeting), อีเมล (Email), งานทั่วไป (Task)
   - กำหนดวันครบกำหนด (Due Date) และระดับความสำคัญ (Priority)
   - เช็คเครื่องหมายเสร็จสิ้นงานได้สะดวกรวดเร็ว

---

## 🛠️ วิธีการรันโปรเจกต์ (Getting Started)

1. **ติดตั้ง Dependencies**:
   ```bash
   npm install
   ```

2. **รัน Development Server**:
   ```bash
   npm run dev
   ```
   เปิดเบราว์เซอร์ไปที่ `http://localhost:3000`

3. **บิลด์สำหรับ Production**:
   ```bash
   npm run build
   npm start
   ```
